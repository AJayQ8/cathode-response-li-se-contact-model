# Source Workbook

The raw Moradi source workbook is not included in this public repository.

Readers should obtain the workbook from the original publication unless
redistribution permission is confirmed. Processed extraction tables used by the
manuscript are provided in:

`data/source_workbook_extractions/`

Those tables include the CCD boundary, pressure-waveform summaries,
EIS/contact-resistance summaries, profilometry/morphology summaries, cycling
context, and consistency ratios used by the reduced-model analysis.
