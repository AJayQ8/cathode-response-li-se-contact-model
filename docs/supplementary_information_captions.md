# Supplementary Information

This document summarizes the journal-facing supplementary figures supplied with
the manuscript.

## Supplementary Figures

**Supplementary Fig. S1. Z-LCO intermediate-coordinate check.** Source-workbook
pressure response and reduced-model consistency outputs are used to examine the
intermediate cathode-response coordinate.

**Supplementary Fig. S2. Multi-current threshold brackets.** Multi-current
threshold-bracket spot checks contextualize the reduced pressure-current regime
map. The low-pressure filling-biased marker in panel (a) is a plotted
lowest-stable-pressure bound.

**Supplementary Fig. S3. Algorithmic flow.** Algorithmic flow from source
calibration to leverage outputs.

**Supplementary Fig. S4. Stability-rule sensitivity.** Stability-rule
sensitivity and threshold-rule envelope for the reduced stability
classification. Shaded bands in panel (c) indicate threshold-rule
envelope/sensitivity ranges.

**Supplementary Fig. S5. Pre-contact strain response-coordinate projection.**
Pre-contact strain response-coordinate projection provides bounded
source-workbook support for the cathode-response ordering.

**Supplementary Fig. S6. High-pressure classification check.** High-pressure
stability-classification behavior shows why high-pressure risk-magnitude
separation does not change the classification conclusion.

**Supplementary Fig. S7. Term-level attribution.** Term-level
attribution/decomposition supports the scalar-amplification interpretation.

**Supplementary Fig. S8. Pressure-taper sensitivity.** Pressure-taper
sensitivity and envelope checks are shown. In panel (c), black corresponds to
zero changed end members per cell and the colored region marks pressure-current
cells with classification changes.
