# Figures

The current manuscript figures are included as final PDF and PNG files. Main figures 1–6 are in `figures/main/`; supplementary Figure S1 is in `figures/supplementary/`. These are figure outputs, not editable vector-source scripts. The supplied `scripts/build_spatial_figures.py` regenerates main Figure 3 and Figure S1 from saved values and data; it does not run the model.
