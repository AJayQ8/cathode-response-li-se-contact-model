# Public Repository Manifest

This folder is intended to become the root of a separate public GitHub/Zenodo
repository for the paper once the manuscript is final.

## Top-Level Contents

- `README.md`: overview, quick start, scope, and release notes.
- `requirements.txt`: Python dependencies for public checks and model code.
- `src/`: reduced Li|SE contact-field model implementation.
- `scripts/`: public verification script.
- `data/`: processed source-workbook extractions, manuscript figure data,
  supplementary analysis data, and supplementary tables.
- `figures/`: final main and supplementary figure files.
- `docs/`: model equations and supplementary-information captions.
- `source_workbook/`: note explaining how to obtain the raw source workbook.

## Excluded From This Folder

- Raw third-party source workbook.
- Old manuscript-package versions.
- Development-only reports and notes.
- Website deployment artifacts.
- Local development-environment files.

## Release Notes

The author-facing public release should add the selected license, final paper
citation, and archive DOI once those records are available.
